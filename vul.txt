Resumen ejecutivo
Es un trabajo grande y germinalmente correcto: 8 commits + un diff sin commitear de ~27 archivos, con 113 tests Python verdes y 3 frentes. Hay avance real de las Etapas 2-6, pero dos riesgos críticos de seguridad en la web console que debes decidir si aceptas (es local, no multiusuario) o mitigar.

1. Frente C++ (core)
AgentSandbox.h (nuevo, sin trackear) — sandbox de efectos con deny-by-default (allow_fs_*, process, network), funciones sandbox_resolve/write_file/read_file que escriben solo bajo work_dir. 🟠 ⚠️ Es dead code: ningún agente nativo lee request.sandbox, y sandbox_resolve (comparación por prefijo de string) es frágil en Windows (case-insensitive de unidad). El "deny-by-default" es retórica hasta que un agente lo consuma. El puntero a stack (AgentSandbox.h:116-126) es colgante si se copia AgentRequest.
LocalPreprocessor — bucle iterativo (preprocess(max_rounds), cpp:98-157), finito (≤max_rounds, max(1, max_rounds)). 🟢 Bien. Cada ronda: analyze_needs (LLM determinista, temp=0), y gather_from_project (lee del índice por paths/símbolos) hasta decidir. 🟠 Riesgo: gather_from_user bloquea std::cin (cuelga el CLI en CI/headless) y gathered_context crece sin cota entre rondas (posible OOM con archivos grandes + max_rounds alto). El fallback a JSON inválido → category=general, sufficient=true evita loops. 🟡 has_enough_context ignora el campo sufficient (gap menor), y gather_from_project es O(n·m) sobre el índice.
config: local_llm_max_rounds = 3 (default), retrocompatible vía value(..., default). 🟡 to_json no persiste max_rounds si use_local_llm=false.
CLI: cmd_run (SatelliteCLI.cpp:792-815) crea el LocalPreprocessor y llama preprocess(goal, max_rounds) si use_local_llm, y pasa refined_prompt al orchestrator. FactoryCLI.cpp no integra preprocesado (solo genera specs). Coherente.
2. Frente Python (satellite_py) — la parte más sólida
25 módulos funcionales, cada uno con su responsabilidad clara. El pipeline semántico de la Etapa 2 está bien reflejado: index.json con mtime + stale_paths() (invalidación) + resolver.resolve(paths, symbols) (contexto por paths, cap 60k) + optimizer determinista (sin LLM) + semantic.py (ContextCompressor intención/restricciones/referencias + SemanticContextRefiner). Esto ES la Etapa 2 + arranque de 4.
E3-E6 coherentes: refined_prompt ✔, NeedInfo/ContextResult/SESSION_SCHEMA neutros al provider ✔, compresión con maybe_recompress (60k) ✔, sanitize_session (E6) solo deja campos neutros ✔.
planner.py con desempate topológico por order (el bug que detecté, arreglado) y rechazo de ciclos. orchestrator.py 583 líneas con red de complementos (_MAX_COMPLEMENT_CHAIN=8 evita ciclos).
🟡 3 extractores JSON casi idénticos (_extract_first_json, _extract_object, _extract_json) — riesgo de drift. timeout=30 fijo en agent_host_bridge. Sin fallback entre providers (si openai sin key → crash; solo la mitigación de 401→pregunta al usuario). env int() sin validar.
3. Web console (satellite_py/web) — 🔴 riesgos críticos de seguridad
FastAPI + Uvicorn, bind a 127.0.0.1 por defecto (mitigado en local), sin auth, sin CORS. Endpoints: /api/system, /api/dirs, /api/project/set, /api/project/init, /api/context/index, /api/agents*, /api/files, /api/file (GET/PUT), /api/file/ask, /api/config, /api/run (+ /wait), etc.
🔴 CRÍTICO:
Sin autenticación — si alguien cambia SATELLITE_WEB_HOST=0.0.0.0, da lectura/escritura de archivos arbitrarios (/api/file PUT), subprocess (/api/project/init corre satellite init) y provisión de config LLM.
/api/project/set acepta CUALQUIER ruta del sistema → apuntando el root a C:\, el límite del root ya no protege → lectura/escritura de todo el disco.
Goal sin sanear → prompt LLM; auto_expand=True.
🟠 ALTO: XSS persistente en askMessage (innerHTML con la respuesta del LLM sin escapar) — un LLM manipulado o un archivo malicioso puede ejecutar JS en la consola → que tiene poder de escritura de archivos. DoS con runs concurrentes sin rate-limit.
🟡 MEDIO: api_key en claro en .satellite/config/ y visible por file_read; CDNs sin SRI.
Integración real: usa store, context, llm, planner, orchestrator, semantic, registry, security + bridges C++. No es prototipo — es una consola de desarrollo local.
